# Takeda BSWS Data Portal

A static GitHub Pages prototype for an unofficial research interface to harmonized public BSWS tables.

## Public website

```text
https://tnozomiecon.github.io/takeda-bsws-data-portal/
```

## Current structure

```text
.
├── index.html
├── styles.css
├── script.js
├── assets/
│   └── favicon.svg
├── data/
│   └── bsws_sample.csv
└── metadata/
    └── variables.json
```

## Important note

The included CSV contains placeholder demo rows only. Replace `data/bsws_sample.csv` with processed public statistics before releasing real data.

## Updating the site

Edit files locally, then in GitHub Desktop:

```text
Commit to main
Push origin
```

GitHub Pages will update automatically.
